# Values reported in the thesis

Transcribed from the labels printed on Figures 6.3–6.6 of the submitted thesis, for comparing a re-run.

- `trir_reported.csv`: mean TRIR (%) over 5 seeds per task, scenario (50E/500R), setup, rewriting model and ε. Rows with `setup = original` are the unprivatized baselines.
- `gamma_reported.csv`: the trade-off score γ for the same configurations.

ROC-AUC, S and C were only reported as line plots (Figures 6.1 and 6.2 in `figures/thesis/`), so no exact values are listed for them.
